> holds it, where the source material lives, and how to rotate it. Values never belong here.

Last reviewed: 2026-09-16. Owner for everything below is Venkat Kuppoor (venk@mercurian.ai)
until Mercurian has a second maintainer; rotation contact is the same person.

## npm

`@mercurian/astrolabe` is reserved on npm under the owner's personal account. Publishing uses
OIDC trusted publishing from `.github/workflows/release.yml`, so no npm token is stored in the
repository. The platform packages still need placeholder publishes and trusted-publisher settings;
see [release-destinations.md](./release-destinations.md).
