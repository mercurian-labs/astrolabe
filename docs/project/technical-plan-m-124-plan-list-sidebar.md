# Technical Plan — M-124: Replace the sidebar: chisel a flat Mercurian plan sidebar out of upstream's redesign

_Generated from the Goal/AC of Linear issue M-124 (see the issue for the full AC). Replaces the M-95 project → plan tree (`docs/project/technical-plan-m-95-projects-plans-tree.md`) with a flat plan-card sidebar chiseled out of upstream T3 Code's sidebar redesign, under [ADR 004](../architecture/fork-baseline.md) (fork posture: dead upstream surface stays typechecking, never deleted). Design source of record is the almagest vault's Left Sidebar note — this issue changes it from tree to flat list + scope filter + archived shelf, and mandates updating it before implementation. The sync half follows `docs/operations/upstream-sync.md` (precedent merge `056c310ad`, precedent plan doc `7f02574d1`)._

**Goal, in one sentence:** throw away `ProjectTreeSidebar` and rebuild the web sidebar as upstream's flat model — a flat list of two-line plan cards scoped by a project filter dropdown, with an amber drafts block, a status slot that cross-fades to actions, and a collapsible Archived shelf at the bottom — landed in three phases: a behavior-neutral full upstream sync first (the redesign and ~11 follow-up sidebar commits sit in the 63 commits we're behind), then the new `PlanListSidebar` chiseled from the synced donor, then retirement of the tree.

**Scope fences, restated from the issue:** pinning + dnd-kit, snooze, multi-select, inline rename, terminals/PR/diff/provider/worktree indicators, and upstream's inline search listbox are skipped entirely. The plan card's line 3 is omitted — all upstream line-3 content is thread/session-domain (branch, PR, diffs, terminals); line 3 returns when coding sessions land under plans. Deliberately deferred one-liners: the Usage footer row, and persisting the scope filter to `uiStateStore`. Decisions of record: adopt upstream's flat model literally (the tree dies); full upstream sync first; archived plans become one collapsible shelf (upstream's "Settled" design), no snooze concept.

## Phase B — Chisel `PlanListSidebar`

New files in `apps/web/src/components/mercurian/`: `PlanListSidebar.tsx`, `PlanListSidebar.logic.ts`, `PlanListSidebar.logic.test.ts`. Donor: post-sync `apps/web/src/components/Sidebar.tsx`. Data: `useMercurianTree()` (`state/mercurian.ts`), `usePlanDraftStore`, `usePlanLifecycleActions`, `useMarkPlanUnread`, repositories state. Plan fields available: `planId, projectId, title, createdAt, updatedAt, hasPendingInput, isWorking, visitedAt?, archivedAt, hasPublishedCommits`. Projects have **no favicon/cwd/branch** — constrains the card.

- [ ] **Before implementing, consult the almagest vault's Left Sidebar note (product-docs skill) and update it** — the design of record changes from tree to flat list + scope filter + archived shelf.

### Copy verbatim from the donor

- Shell: `SidebarChromeHeader` → `SidebarContent className="gap-0" fixedHeader={…}` (our `ui/sidebar.tsx` already has `fixedHeader`) → one flat `<ul>` with auto-animate (`@formkit/auto-animate` already a dep) → `SidebarChromeFooter`.
- Fixed-header markup (donor ~3164–3350): search pill + icon button row; scope-filter `MenuRadioGroup` row + `FolderPlusIcon`.
- `rowSurfaceClassName` (~1011), card geometry (~1240) with the status-slot hover cross-fade idiom, slim h-9 row (~1115), shelf header (muted label + `h-px flex-1` rule + rotating chevron + collapsed count), thin dividers, Show-more paging row, empty states (~3665), amber draft-row visuals (~424–520).

### The plan card (per row)

- **Line 1**: `FolderIcon` (muted, size-4) + project name (`text-xs text-secondary-label`) + right status slot: at rest — `resolvePlanRowStatus` result rendered in upstream's icon+label style (`working` → `CircleDashedIcon` "Working"; `awaiting-input` → their input treatment; null → relative time from `updatedAt`); on hover/focus — cross-fade to **Archive** quick action + `MoreHorizontalIcon` menu.
- **Line 2**: title with upstream's unread weight variants (`unseen` maps to unread title treatment, not a slot label). No inline rename.
- **Line 3: omit** (all upstream line-3 content is thread/session-domain: branch, PR, diffs, terminals). Two-line card, padding-driven height (drop fixed `h-[4.875rem]`). Line 3 returns when coding sessions land under plans.
- Row menu + native context menu: reuse `buildPlanRowMenuItems`/`resolvePlanRowActions` and the dual-surface pattern from `ProjectTreeSidebar.tsx:566–667` (mark-unread / archive / delete-if-private).
- Skip `SidebarThreadTooltip` (session data).

### Fixed header behaviors

- **Search pill**: upstream's pill visuals, but keep it a button that opens our SearchPalette (`openCommandPalette()`), with keycap label via `shortcutLabelForCommand`. Do NOT adopt upstream's inline combobox — M-105's palette owns search.
- **New-plan button** (`SquarePenIcon`): scoped project (or single project) → `openDraftForProject` + navigate `/plans/draft/$draftId`; else open the palette's existing new-plan-in project picker (`SearchPalette.tsx:132,247`). Disabled with zero projects.
- **Scope filter**: `MenuRadioGroup` over `sortProjectsForTree(projects)`, "All projects" default, ephemeral `useState` (matching upstream). Filters drafts + cards + archived shelf; reset shelf paging on scope change. **Gear action** → open our `ManageProjectRepositoriesDialog` for that project (not upstream's `/projects/$projectKey`, which is thread-domain).
- **New-project button** → existing `NewProjectDialog`.

### Body sections (one flat `<ul>`)

1. **Drafts block** (amber): invested drafts only (`text.trim().length > 0`) from `planDraftStore`, scope-filtered; click → draft route; hover X → discard; thin divider below when non-empty.
2. **Active plan cards**: `partitionPlansByLifecycle(...).active`, scope-filtered, `sortPlansNewestFirst`. **No pinned block / dnd, no preview cap** (the flat list is the list).
3. **Archived shelf**: upstream Settled-shelf design; slim rows (dimmed icon, receded title, relative time from `archivedAt`); newest-archived first (lift `sortPlansNewestArchivedFirst` out of `ArchivedPlansPanel.logic.ts`); paging 10 then +25; hover action **Restore** (`unarchivePlan`), menu adds delete-if-private; collapsed by default (local state).
4. **Empty states**: "No projects yet" + Add project; "No plans in {name} yet"; "No plans yet".

### Mercurian features carried over

- **Jump shortcuts (M-105)**: keep `useTreeJumpShortcuts`/`useJumpHintLabels`/`JumpHintBadge` (from `ProjectTreeSidebar.tsx:204–283`); targets = drawn order of active cards (archived excluded).
- **Settings takeover**: keep the `/settings/*` branch inside the component rendering `<SettingsNav/>`, so `AppSidebarLayout` keeps its single-line divergence.
- **Footer**: `SidebarChromeFooter` with Settings row ON; extend the seam with an extra-rows slot for a **Repositories** row (→ `/repositories`) above Settings. Skip upstream's Usage row.
- **Skip entirely**: pinning + dnd-kit, snooze, multi-select, inline rename, terminals/PR/diff/provider/worktree indicators, inline search listbox.

### Logic module (`PlanListSidebar.logic.ts`, tested per repo convention)

`resolveSidebarSelection(pathname)` (extends `resolveTreeSelection` with `activeDraftId`), `filterPlansByProjectScope`, `partitionSidebarPlans` → `{active, archived}`, `resolvePlanCardStatus` → `{slot, unread}`, `pageArchivedPlans` (10/+25), `listJumpTargets`, `resolveDraftRows`.

### Wiring
