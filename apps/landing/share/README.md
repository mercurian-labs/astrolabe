# Share assets

| File                        | Where it goes                                                                                                                                                                 |
| --------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `github-social-preview.jpg` | The repository's Settings → General → Social preview (1280 × 640). GitHub has no file for it in the repository, so re-upload after a re-render.                               |
| `header-1500x500.jpg`       | The X profile header and the LinkedIn banner. LinkedIn crops it to about 4:1, so the frame sits inside that crop; both put the avatar over the lower left, which stays empty. |
| `avatar-400.jpg`            | The X, LinkedIn and GitHub organisation avatar. Every platform crops it to a circle; the monogram sits inside it.                                                             |
